# 美食策划评鉴技能 · Food Planning Assessment

评估一份美食策划案，绝不是简单地打分。它需要你同时扮演食客、美食家与文化观察者——既要问「好不好吃」，更要问「为什么好吃」，以及「它是否尊重了食物本身的灵魂」。

本技能以古今东西方八位美食与营养权威的思想为评鉴支柱，对策划案进行七个维度的系统审查。

---

## 评鉴哲学基础：六位权威的核心思想

在开始评分之前，内化以下评鉴原则——这是本技能的品味基础：

### 袁枚（1716–1797）· 《随园食单》
中国饮食评鉴史上最系统的思想家。核心主张：
- **物性为本**：「一物有一物之味，不可混而同之」——每种食材都有自己的个性，策划者应顺应而非压制
- **戒耳餐**：「不知豆腐得味，远胜燕窝」——拒绝用食材名贵程度代替真正的味觉判断；好的策划案不靠堆砌贵价食材
- **戒目食**：反对追求菜品数量和排场，而应追求每一道的精准
- **火候即道**：「熟物之法，最重火候」——技艺的精准是品质的基础
- **适口者珍**：最终标准永远是入口的感受，而非头衔与名声

### 李渔（1611–1680）· 《闲情偶寄·饮馔部》
将饮食上升为生活美学的哲学家。核心主张：
- **渐近自然**：「饮食之道，脍不如肉，肉不如蔬，亦以其渐近自然也」——越接近天然本味越高级
- **一字之鲜**：蔬食之美，「只在一字之鲜」；鲜味是食材品质的最高体现
- **孤行见真味**：「世间好物，利在孤行」——最好的食材往往不需要复杂的配伍，单独呈现反而最动人
- **俭约之美**：反对油腻与过度调味，在简约中找到饮食之乐

### Jean Anthelme Brillat-Savarin（1755–1826）· 《味觉生理学》
将美食学提升为科学与艺术的西方奠基人。核心主张：
- **"告诉我你吃什么，我就知道你是谁"**——饮食是身份与文化的镜子
- 味觉体验是感官（嗅觉、味觉、视觉、触觉、听觉）的综合交响，策划案需要考虑全感官叙事
- 美食是一种社交仪式，餐桌上的体验具有超越食物本身的精神意义
- 美食学是艺术，更是科学——需要精准的感官分析，而非感性的泛泛而谈

### 米其林评鉴体系（Michelin Guide）· 五项普世标准
当今最具权威性的餐饮评鉴体系，五项核心标准同样适用于策划案：
1. **食材品质**（Quality of Ingredients）
2. **烹饪技法的掌控**（Mastery of Techniques）
3. **口味的和谐**（Harmony of Flavours）
4. **菜品的个性与灵魂**（Personality of the Cuisine）
5. **稳定性与一致性**（Consistency）

### Michael Pollan（1955–）· 《为食物辩护》（*In Defense of Food*, 2008）
从食物文化与公共健康视角审视饮食的当代思想家。核心主张：
- **"Eat food. Not too much. Mostly plants."**（吃食物，不要太多，以植物为主）——以七个字穿透了现代营养学的迷雾
- **反对「营养主义」（Nutritionism）**：不要用营养素分解的眼光看待食物，要看整体的真实食物模式。一份富含天然全食材的策划，胜过一份靠加工食品凑齐营养指标的策划
- **外祖母原则**：如果你的外祖母不认识货架上的某种成分，那它大概率不该出现在一份好的美食策划里
- 饮食既是个人健康的选择，也是对土地、生产者和生态系统的道德表态

### 中国居民膳食指南（2022）· 中国营养学会
中国官方权威营养科学标准，为评鉴膳食营养结构提供量化基准：
- **核心准则：食物多样，合理搭配**——每日≥12种食物，每周≥25种；覆盖谷薯、蔬果、动物性、豆奶、坚果五大类
- **限量红线**：盐<5g/日，烹调油25–30g/日，添加糖<50g/日
- **膳食宝塔**（五层）：谷薯类→蔬菜水果→动物性食物→乳类大豆坚果→油盐糖（由多至少）
- **「东方健康膳食模式」**：浙沪闽粤饮食模式——蔬菜水果丰富、常吃水产品、豆奶充足、清淡少盐，与低心血管疾病发病率显著相关，是本技能的正向参照模式

### Ruth Reichl（1948–）· 《纽约时报》首席餐饮评论家
将饮食评论从消费指南提升为文化批评的当代代表：
- **文化真实性至上**：「如果你要评论日本料理或秘鲁菜，你必须真正去过那些国家，深入研究那里的食物应该是什么样的」
- **餐桌是社会镜像**：好的策划案不只是菜单，它关乎谁在餐桌前、他们在体验什么、这顿饭对他们意味着什么
- **反精英主义**：「豆腐入味，远胜燕窝」（与袁枚同声共鸣）——真正的品味不在于食材的价格，而在于对人的真诚

## 工作流程

为本次评鉴建立一个待办列表，逐项完成。

### 第一步：了解策划案背景

在打分前，先厘清以下信息：

- **策划案类型**：商务宴请 / 主题餐厅菜单 / 节庆宴席 / 私人品鉴会 / 健康食谱 / 其他
- **目标受众**：年龄、文化背景、饮食偏好、预算层级
- **主题与意图**：策划者想传达什么？有无明确主题或叙事线索？
- **约束条件**：季节、地域、预算、厨房设备、团队技能水平

如未提供策划案全文，请要求用户提供菜单列表、主题描述或相关文件。

---

### 第二步：七维评鉴

对以下七个维度逐一评分，每项满分10分，权重各异。

> **「膳食营养 · 健康之道」维度的权重请根据策划类型动态调整：**
>
> | 策划类型 | 营养维度推荐权重 |
> |---|---|
> | 日常健康食谱 / 康养餐饮 | 3.5 |
> | 商务宴请 / 主题品鉴 | 2.0 |
> | 节庆宴席 / 一次性活动 | 1.5 |
> | 医疗膳食 / 特殊人群 | 4.0 |
> | **通用默认** | **2.5** |

---

#### 维度一：食材哲学 · 物性之道  （权重 3.0）
*主要参照：袁枚「物性为本」、李渔「渐近自然」、米其林「食材品质」*

这是策划案的地基。再精妙的技法，也无法拯救一份在选材哲学上失根的策划。

| 评鉴标准 | 说明 |
|---|---|
| 食材本味的尊重 | 策划是否让每种食材表达自己的天然个性？还是用浓重调味遮蔽了本味？（袁枚「物性为本」） |
| 时令与鲜度 | 食材是否顺应时令？鲜度是否被放在优先位置？（李渔「一字之鲜」） |
| 食材品质层级 | 所选食材是否与策划定位相称？有无「耳餐」倾向——仅靠名贵食材堆砌门面？（袁枚「戒耳餐」） |
| 可持续与溯源意识 | 食材来源是否可追溯？是否体现对生产者和自然的尊重？（米其林绿星精神） |

---

#### 维度二：口味结构 · 和谐之道  （权重 3.0）
*主要参照：米其林「口味的和谐」、袁枚「戒混浊」、Brillat-Savarin 感官分析*

口味结构是策划案的骨架。既要有层次，又要有逻辑——就像一首好的交响乐，高潮、过渡、休止符都不可少。

| 评鉴标准 | 说明 |
|---|---|
| 五味平衡 | 酸、甜、苦、咸、鲜（umami）的分布是否均衡？有无某种滋味过度统治？ |
| 口味清晰度 | 每道菜的口味主线是否清晰？还是「戒混浊」所批评的混杂无序？ |
| 质感与口感的对比 | 全局是否有酥脆与柔软、清爽与醇厚的交替？质感单一会令用餐疲惫 |
| 整体风味递进 | 从头盘到主菜到甜品，口味浓淡、轻重是否有合理的叙事逻辑？ |

---

#### 维度三：主题意境 · 文化之道  （权重 2.5）
*主要参照：Ruth Reichl「文化真实性」、袁枚「戒落套」、Brillat-Savarin「饮食是文化镜像」*

一份有灵魂的策划案，必然有文化根基和清晰的叙事。没有主题的菜单只是一张食品清单。

| 评鉴标准 | 说明 |
|---|---|
| 主题一致性 | 所有菜品是否服务于同一个主题叙事？还是拼凑感强？ |
| 文化真实性 | 涉及某一地域或民族菜系时，是否具有真正的文化理解，而非表面借用？（Ruth Reichl 的核心警示） |
| 创意与独特性 | 策划是否有自己的视角和立场？还是「戒落套」所批评的俗套拼盘？ |
| 情感与记忆连接 | 菜品能否唤起某种情感共鸣或文化记忆？「告诉我你吃什么，我就知道你是谁」 |

---

#### 维度四：烹饪技艺 · 匠心之道  （权重 2.5）
*主要参照：米其林「烹饪技法的掌控」、袁枚「火候须知」*

技艺是策划案能否落地的保证。一份脱离执行能力的策划，无论多美好，都是空中楼阁。

| 评鉴标准 | 说明 |
|---|---|
| 技法的适宜性 | 每道菜所用的烹饪技法是否是呈现该食材最佳状态的最优选择？ |
| 技法的精准要求 | 策划的技法难度是否与执行团队的技能水平匹配？ |
| 创新与传统的平衡 | 是否有技法层面的创新？创新是否有根基，而非为新而新？ |
| 火候与时机的考量 | 策划是否考虑到菜品呈现的时间节奏？（袁枚「戒停顿」——现熟现吃才能锁住鲜泽） |

---

#### 维度五：宾客体验 · 宾主之道  （权重 2.0）
*主要参照：Brillat-Savarin「美食是社交仪式」、袁枚「上菜须知」、Ruth Reichl「餐桌是社会镜像」*

再好的菜品，若体验设计糟糕，也会大打折扣。这个维度评估策划案的「叙事流动性」——它能否引导宾客完成一段有起伏、有记忆点的饮食旅程。

| 评鉴标准 | 说明 |
|---|---|
| 上菜节奏与流程 | 菜品的出场顺序是否合理？节奏是否有张有弛？ |
| 饮食旅程的叙事弧线 | 整套策划是否有「序幕—发展—高潮—尾声」的完整体验弧？ |
| 对话性与互动空间 | 策划是否为宾客之间的交流留出了空间，而非密集轰炸让人应接不暇？ |
| 包容性与文化体贴 | 是否考虑了不同饮食偏好、宗教禁忌或身体需求的宾客？（Ruth Reichl 的民主精神） |

---

#### 维度六：可行落地 · 现实之道  （权重 1.5）
*主要参照：米其林「稳定性与一致性」*

评鉴者不应只活在理想中。一份策划案的价值，最终体现在它能否被高质量地执行。

| 评鉴标准 | 说明 |
|---|---|
| 采购可行性 | 所需食材是否在执行时间和地点内可稳定获取？ |
| 预算合理性 | 策划的食材与技法要求是否与预算定位相符？ |
| 厨房执行效率 | 多道菜同时出品时，是否考虑了厨房动线与出菜节奏的协调？ |
| 可复制性与稳定性 | 若策划用于持续运营（而非一次性活动），菜品品质能否稳定重现？ |

---

#### 维度七：膳食营养 · 健康之道  （默认权重 2.5，可调整）
*主要参照：中国居民膳食指南（2022）量化标准、Michael Pollan「全食物原则」*

营养不是美食的对立面，而是好策划的隐形基础。最高境界是：让宾客在享受味觉盛宴的同时，身体也得到善待。

> **Pollan 原则**：不要用营养素数学来打分。一份天然全食材构成、宏量营养素稍有失衡的策划，营养分数应高于一份靠加工食品凑齐指标的策划。「吃食物」永远排在「吃营养素」之前。

| 评鉴标准 | 说明 |
|---|---|
| 食物多样性 | 策划是否覆盖谷薯、蔬果、动物性食物、豆奶、坚果五大类？日均品种是否≥12种？（膳食指南核心标准） |
| 三大营养素结构 | 碳水化合物、蛋白质、脂肪的大致比例是否均衡？是否存在某类营养素过度集中（如高蛋白宴席缺乏全谷物与蔬菜）？ |
| 微量营养素与膳食纤维 | 食材组合能否提供充足的维生素、矿物质和膳食纤维？深色蔬菜、全谷物、豆类是否有足够比重？ |
| 低盐低糖控油 | 烹饪方式和调味习惯是否体现健康意识？重油重盐的菜品是否有合理比例控制？（参照：盐<5g/日、油25–30g/日标准） |
| 受众营养适配 | 是否针对目标受众的特殊需求（老人减盐补钙、儿童补铁补锌、孕妇增叶酸、运动员高蛋白、减重者控热量）做出针对性调整？ |

### 第三步：计算加权总分

```
各维度标准化分 = mean(该维度各标准得分) / 10     # 归一化到 0.0–1.0
总分 = Σ(权重_i × 维度分_i) / Σ(权重_i)         # 加权平均
最终展示 = 总分 × 10                             # 还原到 0–10 分制
```

各维度默认权重汇总：
| 维度 | 默认权重 |
|---|---|
| 食材哲学 · 物性之道 | 3.0 |
| 口味结构 · 和谐之道 | 3.0 |
| 主题意境 · 文化之道 | 2.5 |
| 烹饪技艺 · 匠心之道 | 2.5 |
| 宾客体验 · 宾主之道 | 2.0 |
| 可行落地 · 现实之道 | 1.5 |
| 膳食营养 · 健康之道 | 2.5 |
| **合计** | **17.0** |

### 第五步：提供后续深化方向

报告完成后，至少提供以下一项：
- **最低分维度的深度改善建议**（具体到菜品调整）
- **标杆参照**：列举1–2个在该弱项维度上出色的真实案例
- **菜单重构建议**：在保留核心主题的前提下，给出若干具体菜品替换或顺序调整的建议
- **量身评鉴**：若用户希望针对特定受众（如外国宾客、素食者、高端商务）重新评分，可调整各维度权重后再次出具报告

## 评鉴者须知：如何用好这套标准

1. **先「闻其声」，后「辨其味」**——即袁枚「戒耳餐」精神：不要被菜名、食材标签或价格先入为主，要回到食物本身的逻辑去思考。

2. **区分「技法复杂」与「真正好吃」**——Michelin 的「技法掌控」维度并不奖励复杂性本身，而是奖励「技法服务于口味」。一道完美的清蒸鱼，比一道失败的分子料理高级。

3. **承认主观，但说清为什么主观**——李渔的「渐近自然」与米其林的「个性」之间存在真实的张力：前者崇尚减法，后者欣赏独特风格表达。评分时若二者相悖，应在小结中明确指出这种张力，而非回避。

4. **文化理解是不可妥协的底线**——引用 Ruth Reichl 的标准：评论一道你不熟悉的菜系前，必须先承认自己知识的边界，并用「（置信度：中）」或「（置信度：低）」标注相应标准的评分。

5. **永远不要因为「太主观」而拒绝给出评价**——主观性不是逃避判断的理由，而是让你的推理过程更加透明的要求。

6. **不要用营养素数学代替对真实食物的判断**（Michael Pollan 的核心警示）——宏量营养素比例完美、却大量依赖加工食品或营养补剂的策划，其营养维度分数应低于食材天然、整体配比稍有缺陷的策划。「吃食物」始终优先于「吃营养素」。若策划中出现大量超加工成分（人工添加剂、代餐粉、合成香料主导），应在「食物多样性」标准项下如实扣分并注明原因。
