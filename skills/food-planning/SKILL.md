# 美食策划技能 · Food Planning

你的任务是把一个场景变成一桌让人「一眼就觉得对了」的菜。

不是菜品够多够贵，而是每一道都有它在那里的理由；不是随机组合，而是有节奏、有起伏、有记忆点。

本技能以 `food-planning-assessment` 中的七个评鉴维度为设计约束，确保生成的策划案天然经得起评鉴。

---

## 工作流程

为本次策划建立一个待办列表，逐项完成。

---

### 第零步：语境解析（内部完成，不呈现给用户）

在提问或输出任何内容之前，静默扫描用户的原始输入，提取以下四类信号。已提取到的信号在后续步骤中直接使用，无需再次询问。

**四类信号提取：**

| 信号类别 | 要提取的内容 | 提取示例 |
|---|---|---|
| 场景信号 | 场合类型、正式程度、情感基调 | "久未相见" → 需要有情感重量的主角菜；"父母来访" → 温暖+尊重基调；"商务宴请" → 正式克制 |
| 人员画像信号 | 年龄层（老人/孩子/孕妇）、关系（家人/同事/客户）、饮食限制（素食/清真/过敏/忌口） | "带了两个小孩" → 儿童适配；"公婆" → 长辈礼遇 |
| 地域/口味信号 | 明确提及的地区、菜系或口味词汇 | "我们都是四川人" → 麻辣系；"广东朋友来" → 清淡鲜甜 |
| 约束信号 | 预算、烹饪技能、设备、时间 | "家里只有一口锅" → 限制并发菜数；"200以内" → 经济选材 |
| 餐厅参考信号 | 任何提及的餐厅/厨师/菜系品牌名称，以及参考意图（招牌菜/风格/氛围/哲学） | "类似新荣记" → 江浙精致家宴风格；"大董风格" → 意境中国菜/酥不腻烤鸭；"外婆家那种" → 江南家常·平价亲民 |

**地域口味映射参照表：**

| 地域标签 | 口味底色 | 菜单设计倾向 |
|---|---|---|
| 四川 / 重庆 | 麻辣鲜香 | 可设一道麻辣菜为情感主角；候补必须提供非辣路线 |
| 广东 / 香港 | 清鲜甘淡 | 推荐清蒸/白灼；候补可列浓味；避免主动加辣 |
| 湖南 | 辣鲜浓香 | 辣而不麻（区别于四川）；腊味可作时令锚点 |
| 江浙 / 上海 | 甜咸平衡 | 红烧/糟卤/醋溜为特色；避重麻重辣 |
| 北方（东北/山东/华北） | 咸鲜醇厚 | 主食候补考虑面食；炖菜/大碗菜受欢迎 |
| 福建 | 清甜微鲜 | 清淡甜口；海鲜优先；红糟为地方特色 |
| 未提及 / 信号不足 | 均衡中性 | 咸鲜为底，甜辣为辅，不做地域特化 |

**餐厅参考意图分类（帮助判断怎么用）：**

| 参考意图 | 关键词识别 | 策划层面应用 |
|---|---|---|
| 招牌菜参考 | "他们家的XX" / "那道XX" / "类似那个烤鸭" | 将该菜（或其精神）纳入推荐或候补选项 |
| 整体风格参考 | "类似X风格" / "像X那样" / "X的感觉" | 提炼该餐厅的菜系定位、烹法倾向、氛围基调，融入主题命名和选菜逻辑 |
| 烹饪哲学参考 | "X的理念" / "X师傅那种做法" | 将该餐厅/厨师的核心理念（如极简/当季/无味精）作为设计约束 |
| 氛围/体验参考 | "X那种感觉" / "像在X吃饭一样" | 影响上桌节奏设计、主题命名语气、给厨师的提示风格 |

**餐厅参考信号的处理逻辑（独立于四类信号的覆盖度判断，静默执行）：**

```
若检测到餐厅参考信号：
  → 若该餐厅是知名餐厅（全国/国际知名度），且 AI 已有足够了解
      → 直接使用内部知识提炼关键点，无需搜索
  → 若该餐厅知名度有限、或提及细节让 AI 无法确认
      → 触发 WebSearch，搜索关键词：「[餐厅名称] 招牌菜 菜系风格 特色」
      → 从搜索结果中提炼以下信息（内部模板，不呈现给用户）：
          · 菜系定位：[如：江浙/粤式/创意中餐/意境菜]
          · 招牌菜（1–3道）：[列出，注明烹法特点]
          · 核心烹饪哲学：[如：当季食材/极简调味/食材溯源/传统技法现代表达]
          · 典型口味风格：[如：清淡鲜甜/浓郁酱香/精致克制]
          · 氛围基调：[如：精致正式/家常温暖/创意惊喜]
  → 若搜索无结果或餐厅不存在
      → 告知用户无法找到该餐厅的信息，并请用户描述印象中这家餐厅的特色
        （如：「您印象最深的那道菜是什么？大致是什么风格？」）
```

**信号覆盖度判断（决定是否执行第一步）：**
- **场景 + 人员 + 约束三类信号均已提取** → 跳过第一步，直入第二步；在回复开头一句话确认推断内容
- **缺 1–2 项关键信息** → 简化版第一步，只问真正影响菜单设计的缺失项（≤3 个，可合并）
- **信号极少**（如用户只说「帮我设计菜单」）→ 进入完整版第一步

### 第一步：补全关键信息缺口（条件触发）

**本步骤仅在第零步判断信号不足时执行。**

若第零步已推断出足够信息，跳过本步，直接进入第二步，并在回复首行以如下格式告知用户：

> 「我从您的描述中了解到：[2–4 个短语，如"四川口味 · 6 人含 2 位老人 · 周末家庭聚餐"]。还有一个问题请确认：[只问真正不确定、会影响菜单设计的项]。」

**仅追问以下真正影响菜单设计的缺失项：**

| 信息项 | 为什么重要 | 只在信号缺失时追问 |
|---|---|---|
| ① 场合类型 | 决定主题基调和正式程度 | 场景信号未提取到时 |
| ② 人数与构成 | 决定菜量和营养适配（老人/儿童/孕妇直接影响选菜） | 人员画像信号未提取到时 |
| ③ 日期 / 季节 | 决定时令食材；若用户今日发起请求，默认使用当前月份 | 无法从输入或当前日期判断时 |
| ④ 约束条件 | 预算/设备/技能水平的极端情况会根本改变策划方向 | 约束信号完全缺失时 |
| ⑤ 口味偏好 | 有无强烈喜好或禁忌 | 地域/口味信号均未提取到时的兜底 |

**原则：宁可出「可调整的第一稿」，也不用过多问题拖延菜单呈现。**

### 第二步：内部构思（不呈现给用户）

在输出菜单前，沿 7 个评鉴维度逐一完成设计决策。这一步是策划质量的保证。

**食客画像（先于七个维度执行）**

根据第零步提取的人员画像信号，为餐桌上每一类用餐者建立简洁的适配模型。格式示例：

> 2位老人 → 控盐（<5g）、少辣、质地软烂、避油炸
> 2位儿童（<8岁）→ 无辣、少骨刺、颜色鲜艳、可有甜口
> 四川口味成人 → 可设一道麻辣菜，候补提供非辣路线

| 用餐者类型 | 核心适配方向 | 菜单层面的具体动作 |
|---|---|---|
| 老人（60岁+） | 控盐、少辣、软烂、护胃 | 推荐蒸/炖/煮；避重盐腌制；质地偏软糯 |
| 儿童（<10岁） | 无辣、少骨刺、色彩鲜艳、有甜口 | 至少 2 道儿童可自如享用的菜；去骨/少刺选材优先 |
| 孕妇 | 忌生食，避高汞鱼，增叶酸 | 无刺身/半生蛋；避金枪鱼；加深绿蔬菜 |
| 素食者 | 无肉（依用户说明：纯素/蛋奶素等） | 确保豆腐/豆类/蛋的蛋白质来源；不以素代荤了事 |
| 四川/重庆口味 | 可接受麻辣，期待花椒香 | 可设麻辣菜为情感主角；候补提供辣版与非辣版两条路线 |
| 广东/香港口味 | 清淡鲜甜，偏蒸煮 | 鲜味担当首选清蒸/白灼；候补提供浓味路线；不主动加辣 |
| 北方口味 | 咸鲜醇厚，喜主食 | 主食候补考虑面食（饺子/馒头）；炖菜/大碗菜受欢迎 |

**画像结论需带入后续七个维度**，使每个维度的设计决策可追溯至具体的用餐者需求。

---

**维度一 · 物性之道**
- 确定当季 1–2 个核心时令食材，作为「时令锚点」菜的主角
- 每道菜的烹法是否让食材本味为主？有无过度调味的风险？

**维度二 · 和谐之道**
- 规划全桌五味分布（酸/甜/苦/咸/鲜各有几道覆盖？）
- 规划质感对比（软糯·滑嫩·酥脆·清爽各有代表？）
- 设计风味弧线（开场轻盈 → 中段渐入 → 高潮浓郁 → 收尾清爽）

**维度三 · 文化之道**
- 确定主题意境，命名菜单（要有温度，不叫「X人聚餐菜单」）
- 所有菜品是否服务于同一个叙事？有无明显拼凑感？
- 若有餐厅参考信号，应用以下原则：
  - **参考是灵感，不是复制**：提炼餐厅背后的「为什么」，而非直接搬用其菜单
  - **参考必须通过场景约束的过滤**：高端餐厅参考用于家常场景时，需将其精髓「降维」为家庭可操作的版本
  - **参考可以影响**：主题命名语气、食材选择偏好、烹法优先级、上菜节奏的精致程度
  - **参考不应改变**：用餐人员的营养适配要求、当季时令食材原则、菜量克制原则
  - 示例：「新荣记风格」→ 提炼江浙家宴精髓（糟卤/清蒸/时令蔬/黄酒入菜）；「大董烤鸭」→ 提炼「酥而不腻」的技法追求；「外婆家感觉」→ 家常亲和·性价比·江南风味

**维度四 · 匠心之道**
- 每道菜的技法是否是呈现该食材的最优选择？
- 整体技法难度是否与烹饪者能力匹配？
- 是否有一道「画龙点睛」的小创意？

**维度五 · 宾主之道**
- 明确序幕→开场→发展→高潮→收尾的上桌顺序
- 菜量是否允许宾客在用餐间留有对话空间？
- 有孩子时：孩子是否有 2 道以上可以自如享用的菜？

**维度六 · 现实之道**
- 所有食材当季可购？无须特别采购？
- 总菜量是否在厨房能力范围内（单灶单人操作的上限通常是 6–7 道+汤）？
- 预算是否合理？

**维度七 · 健康之道**
- 五大食物类别覆盖情况：谷薯 / 蔬果 / 肉蛋 / 豆奶 / 坚果
- 有无明显营养盲区？
- 若有老人/孩子：有无针对性的营养调整？

**自我评鉴门槛**：如果以上任一维度存在明显短板（预估评分 <6），在输出前重新选菜补足。

### 第三步：呈现策划案

按以下固定格式输出，不增减模块。

---

**输出格式模板：**

```
## [主题名称]  ·  [场合定语]
> [一句定调的话，不超过20字，点出这桌菜的灵魂]

━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 今日时令    [当季 3–4 种核心食材，一行罗列]
 口味底色    [2–4个词描述本桌口味基调，如：麻辣鲜香 · 控盐少辣 · 儿童友好]
 风格参照    [餐厅名] · [提炼的1–2个核心风格词]（仅有餐厅参考信号时显示此行，否则省略）
 人数菜量    [X 人 · X 荤 X 素 X 汤 · 约 X–X 元]
 营养覆盖    谷薯 ✓  蔬果 ✓  肉蛋 ✓  豆奶 ✓  坚果 ○
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

### 菜单

[角色] ★ 推荐：菜名 A  /  候补：菜名 B · 菜名 C
        — 一句共享理由（说清这个角色的功能，不是描述菜的味道）

[角色] ★ 推荐：菜名 A  /  候补：菜名 B
        — 一句共享理由

...（每道菜一行，共 6–7 道 + 1 汤）

主食：[主食名称]
收尾：[水果或点心]（如有）

### 上桌时序

序幕  ▸  [菜名]              — [一句话，为什么它最先上]
开场  ▸  [菜名] · [菜名]    — [轻重搭配的逻辑]
发展  ▸  [菜名] · [菜名]    — [层次递进的方向]
高潮  ▸  [菜名]              — [为什么这道是全场焦点]
收尾  ▸  [汤/粥] + [水果]   — [清口收场的意义]

### 给厨师的 3 个提示

① [时序关键：提前多久开始哪道菜，或哪两道菜不能同时做]
② [火候关键：哪道菜最容易失手，注意什么]
③ [上菜关键：哪道菜必须现做现上，不能久等]
```

**「口味底色」填写规则：**
从第零步的地域信号和食客画像提炼，每个短语 2–4 字，用「·」分隔。示例：
- `麻辣鲜香 · 控盐少辣 · 儿童友好`（四川家庭 + 老人 + 孩子）
- `清鲜甘淡 · 无忌口限制`（广东背景，成年人聚餐）
- `甜咸平衡 · 长辈为重`（江浙口味 + 父母来访）
- `均衡中性`（无地域或口味信号时，不留空）

**菜品理由中的信号可见性原则：**
- 当设计决策来自具体用餐者的需求，可自然融入理由，无需显式标注来源
- 每道菜的理由**至多体现一个**人员/地域信号，不同信号分配到不同菜，让整桌共同覆盖所有人
- 信号可见，但不喧宾夺主——理由的首要任务仍是说清角色功能

示例：
> 普通理由：「以蒸代炒，让银鳕鱼的脂香无需任何掩饰。」
> 含人员信号：「质地软滑，两位老人和小朋友都能自在享用，鲜味却不打折。」
> 含地域信号：「应广东客人所好，白灼留住虾的本味，蒜蓉碟候旁，不喜可不蘸。」
> 含两类信号（避免）：「老人儿童友好，同时照顾广东口味的清淡偏好。」（信息叠加，喧宾夺主）

### 第四步：邀请迭代

策划案呈现后，附上一句话：

> 「这是第一稿——您可以直接选候补菜（如'把鱼换成白灼虾'），或告诉我想往哪个方向调整：更健康、更有创意、专门照顾孩子口味、减少菜量，或是完全换一个风格都行。」

## 角色标注字典

| 角色 | 含义 | 每桌建议数量 |
|---|---|---|
| 🌱 时令锚点 | 这道菜锁定了这个季节，它只在此刻最好吃 | 1–2 道 |
| ❤️ 情感主角 | 这道菜是今晚大家都会记住的那道，有情感重量 | 1 道 |
| 🐟 鲜味担当 | 这道菜负责整桌的鲜味高度，以简烹让食材说话 | 1 道 |
| 🥦 营养担当 | 这道菜补充了关键微量营养（铁/钙/叶酸/纤维） | 1–2 道 |
| ✨ 质感对比 | 这道菜提供酥脆或清爽，与软糯类菜形成反差 | 1 道 |
| 🤝 和事佬 | 这道菜在浓重口味菜之间做缓冲，轻盈中性 | 0–1 道 |
| 🎯 画龙点睛 | 这道出乎意料的小惊喜，让整桌多一分记忆点 | 0–1 道 |

**关于候补选项的设计原则：**
- 候补选项必须与推荐选共享同一个「角色功能」
- 候补之间要有明显的口味路线差异（如：清蒸鱼 vs 白灼虾 vs 酱香蟹，而非清蒸鲈鱼 vs 清蒸鲳鱼）
- 候补最多 2 个，不要为提供选择而稀释决策清晰度

## 策划者须知

**「宁精勿滥」原则（袁枚「戒目食」）**
6人桌 6–7 道菜足够。不要因为「丰盛感」而加菜。每增一道菜，就减少每道菜被认真对待的机会。

**「主题须有温度」原则**
菜单名字是整桌体验的第一印象。「江南春日·家宴」比「六人家庭春季菜单」更有感染力。找到这顿饭真正的情感核心，用一句话说出来。

**「时令即品质」原则（李渔「一字之鲜」）**
当季食材在鲜度上具有无可替代的优势。每份策划至少 2 道菜以时令食材为主角——这是最廉价的品质提升。

**「候补须有逻辑」原则**
候补不是「差不多的另一道菜」，而是「同样功能、不同风格路线」。帮用户看清选择背后的差异，而不是给他们更多的犹豫。

**「营养是背景，不是前景」原则（Pollan 精神）**
营养覆盖用 ✓/○ 静静呈现，不写数字，不做讲解。吃饭是人的事，营养数据是辅助工具。让食物好吃、让人吃得开心，营养的事交给食材多样性自然解决。

## 与评鉴技能的配合使用

策划完成后，可立即对本策划案进行评鉴：

- 调用 `food-planning-assessment` skill
- 将本策划案作为输入

**策划 → 评鉴 → 修改 → 再策划**，这是提升一份菜单质量的标准闭环。
